## Model Training Strategy

This project aims to predict the **Remaining Useful Life (RUL)** of strawberries using image sequences collected throughout the fruit degradation process.

Instead of classifying fruit quality into predefined categories, the proposed approach estimates the remaining shelf life of a strawberry as a continuous value (e.g., remaining days or hours before spoilage). Therefore, the task is formulated as a **regression problem**.

### Overview

The proposed architecture combines convolutional neural networks (CNNs) for spatial feature extraction with recurrent neural networks (RNNs) for temporal sequence modeling.

The pipeline consists of three main stages:

1. **Spatial Feature Extraction**
    - Extract visual features from each image frame using a pretrained CNN backbone.
    - Two CNN architectures are evaluated:
        - EfficientNet
        - MobileNet

2. **Temporal Sequence Modeling**
    - Capture temporal changes in fruit appearance across multiple observation days.
    - Two recurrent architectures are evaluated:
        - GRU (Gated Recurrent Unit)
        - LSTM (Long Short-Term Memory)

3. **Regression Head**
    - The temporal representation generated by the recurrent network is passed to a regression head.
    - The model outputs a continuous RUL value representing the estimated remaining shelf life of the strawberry.

### Experimental Models

To investigate the influence of both feature extraction and temporal modeling components, four hybrid architectures are implemented and compared.

| Model ID | CNN Backbone | Temporal Model | Output         |
| -------- | ------------ | -------------- | -------------- |
| Model A  | EfficientNet | GRU            | RUL Prediction |
| Model B  | EfficientNet | LSTM           | RUL Prediction |
| Model C  | MobileNet    | GRU            | RUL Prediction |

### Training Pipeline

```text
Raw Strawberry Images
          ↓
Image Preprocessing
          ↓
Train / Validation / Test Split
          ↓
CNN Feature Extraction
(EfficientNet or MobileNet)
          ↓
Feature Sequences
          ↓
Temporal Modeling
(GRU or LSTM)
          ↓
Regression Head
          ↓
Remaining Useful Life Prediction
```

### Feature Extraction

Feature extraction is performed as an independent preprocessing stage.

For each image sequence:

1. Images are passed through the selected CNN backbone.
2. High-level visual features are extracted.
3. The resulting feature vectors are stored and reused during model training.

This design offers several advantages:

- Reduces computational cost during experimentation.
- Enables direct comparison between GRU and LSTM architectures.
- Avoids repeated CNN inference for every training run.
- Improves reproducibility of experimental results.

### Regression Objective

The model learns to estimate the remaining shelf life of a strawberry based on its visual appearance and temporal degradation patterns.

Given a sequence of observations:

```text
X = {x₁, x₂, ..., xₜ}
```

the model predicts:

```text
ŷ = Remaining Useful Life (RUL)
```

where:

- xₜ represents the strawberry image at time step t.
- ŷ is a continuous numerical value indicating the predicted remaining shelf life.

### Evaluation Metrics

Since this is a regression task, model performance is evaluated using regression metrics rather than classification metrics.

The following metrics are used:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Percentage Error (MAPE)
- Coefficient of Determination (R² Score)

In addition, training time and inference time are recorded to assess computational efficiency.

### Objective

The objectives of this study are:

- To determine which CNN backbone extracts more informative visual representations of fruit degradation.
- To compare the effectiveness of GRU and LSTM in modeling temporal changes during the spoilage process.
- To identify the CNN–RNN combination that provides the most accurate Remaining Useful Life prediction for strawberries.
- To establish an efficient deep learning framework for shelf-life prediction using non-destructive image-based monitoring.
